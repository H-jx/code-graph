## 一、字段说明

本表沿用 Excel 原表结构，列含义如下：

| 字段 | 说明 |
| :--- | :--- |
| 序号 | 业务条目序号；同一序号跨多行表示同一业务的多步操作或多个角色 |
| 所属模块 | 业务所属的 ERP / 业务模块，例如「采购-生产物料采购申请」 |
| 业务功能 | 业务功能域 |
| 流程 | 具体流程节点或步骤 |
| 一级部门 | 一级组织部门 |
| 二级部门 | 二级组织部门 |
| 角色 | 执行该权限的系统角色；多角色以换行分隔 |
| 权限（动作 / 对象） | 动作 + 对象组合；包含「权限」主列与子列「动作」「对象」 |
| 备注 | 业务说明、条件约束、新增角色说明、SoD 要求等 |
