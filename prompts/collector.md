# 生成采集插件（collector）

> 骨架文件。运行时注入：选定能力、已调查约定、来源快照、脚本模板位置、当前契约与预算。

## 目标

为本项目生成可运行的提取脚本 + `manifest.json` + 验收样例，输出统一事实协议。

## 必须包含

| 产物 | 内容 |
| --- | --- |
| 脚本 | routes / frontend / api / database，或注释、业务模块、自定义入口等能力；同一输出格式 |
| link 脚本 | 读取已有实体，依据明确绑定建立跨层关系 |
| manifest | ID、版本、协议版本、能力、阶段（extract / link）、运行命令、入口、制品哈希、输入选择、依赖 |
| 验收样例 | 正常链路、同名误关联、动态值、遗漏目标、源码变化后的预期结果 |

## 运行约定

- 脚本只通过 JSON stdin/stdout 与 Rust 交互；不假设被交互式调用。
- 读取来源用 Core 导出的快照，不自行扫描工作区。
- 输出携带实体、关系、证据、依赖和覆盖缺口；抓不到的写缺口，不猜。
- 依赖只声明在 manifest 与 `deps/`，运行由 Core 负责。
