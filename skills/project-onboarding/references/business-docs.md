# 业务文档与流程资料整理规范

> 骨架文件。用于约定：哪些内容可以作为业务依据，怎样标注未知项。

## 可以采信的材料

| 材料 | 用法 |
| --- | --- |
| 已有操作说明、流程文档 | 作为状态与操作顺序的依据，记录文件与版本 |
| 已有 SQL / ORM 查询 | 台账口径优先从真实查询还原：字段来源、粒度、聚合、关联条件 |
| 状态字段的枚举与常量定义 | 判定“有效状态”和前后单据键 |
| 数值验收样例 | 人工真值，保持独立，不被生成物覆盖 |

## 必须标注的情况

- 只从调用顺序推断出的“流程顺序” → `inferred`，并注明未获业务确认。
- 统计口径中的时间字段、去重规则、有效性过滤未确认 → 写入待验证项，不写入口径结论。
- 页面或表未采集 → “未采集”，不写“不存在”。

## 输出

主题产物包含：结论、跨层链路、页面操作、后端与数据、取数口径、证据列表、推断与未知项、
覆盖缺口。引用必须与所用索引快照一致；快照过期时先刷新或明确按旧版本调查。
